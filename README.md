# Demos

Public video demos by Andrii Yevenko, served with GitHub Pages at https://ytsuhen.github.io/Pub-demos/.

- [`first-visit/`](first-visit/): a business-analysis demo for homecare software. One caregiver's first visit, shown twice (texts and paper vs an app), then the visit's state machine, transition matrix, requirements traced to their sources, and a pre-fill trade-off. The agency, people and app are fictional; the narration is synthesized from the author's own voice.
